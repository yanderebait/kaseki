# Kaseki documentation

Kaseki is a private, self-hosted dashboard for one person's working life — tasks, schedules, notes, documents, and a sensitive folder, all on your own machine with nothing synced to the cloud.

- **[User Guide](./user-guide.md)** — using Kaseki day to day.
- **[Developer Guide](./developer-guide.md)** — architecture, conventions, and working on Kaseki itself.
- **[Self-Hosting Guide](./self-hosting.md)** — installing, where your data lives, backup, encryption, and privacy.
